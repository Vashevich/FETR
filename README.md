# ФЕТР — параметрический потолок в сетку Армстронг

Конфигуратор ламельных кассет из фетра для подвесного потолка Армстронг.
Открыть: https://vashevich.github.io/FETR/

Что умеет:

- сетка потолка: число ячеек, шаг 600/625/610, профиль T24/T15, плиты и светильники кликом по плану;
- девять готовых узоров и ручная настройка: тип, размер, направление, высоты, изломы, ступени, уклон, затухание к краям;
- 3D-вид снизу, план с номерами кассет и карта сборки;
- раскрой по листам с вложением ламелей парами;
- выгрузка архива для ЧПУ: DXF по листам и по деталям (слои CUT, CUT_IN, MARK, SHEET, миллиметры), спецификация и карта сборки в CSV.

Конструкция кассеты: крышка лежит на полках профиля, шипы ламелей проходят сквозь пазы крышки,
два ригеля-шпонки продеваются сквозь окна шипов и держат ламели. Клей и крепёж не нужны.

Весь проект — один файл `index.html` без внешних библиотек.
